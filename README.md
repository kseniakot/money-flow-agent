# Money Flow Agent

Локальный Telegram-бот учёта личных расходов. Расходы приходят текстом, голосом или фото (чек / выписка из банка), локальная модель их парсит, бот показывает распознанное на проверку, а после одобрения пишет в SQLite. Кошельки по валютам, накопления, подписки, отчёты с диаграммами. Всё крутится на твоей машине — данные никуда не уходят.

## Что умеет

- **Текст** — «молоко 1.92, бананы 4.32 (2.01 за кг), наушники 30 usd» → распознаёт количество, цену за единицу, вес по кг, валюту.
- **Голос** — транскрипция через Whisper, дальше как текст.
- **Фото** — модель сама определяет, чек это или скриншот банковских списаний (с подписью-расшифровкой), и извлекает позиции.
- **Проверка перед записью** — бот присылает читаемое превью с кнопками ✅/❌. Любое сообщение (текст/голос) во время проверки = правка: «молоко не 1.92 а 2.10», «убери яйца», «валюта евро».
- **Кошельки** — по одному spending- и savings-кошельку на валюту, баланс выводится в USD по курсу Нацбанка РБ. Расход бьёт по кошельку своей валюты, минус разрешён.
- **Подписки** — ежедневный джоб списывает подписки в заданный день месяца и уведомляет с кнопкой отмены.
- **Отчёты** — `/report` за период: разбивка по категориям + круговая диаграмма.

## Требования

- Python 3.12, [uv](https://docs.astral.sh/uv/)
- [LM Studio](https://lmstudio.ai/) с моделью **Qwen3-VL-8B-Instruct (MLX)** и запущенным локальным сервером
- `openai-whisper` (CLI) — для голосовых
- `ffmpeg` — Whisper использует его для чтения аудио
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather)

## Установка

```bash
uv sync
brew install ffmpeg           # если ещё нет
pip install -U openai-whisper # если ещё нет (ставится системно, вызывается как CLI)
```

## Настройка

Скопируй `.env.example` в `.env` и впиши токен:

```bash
cp .env.example .env
```

```
TG_TOKEN=<токен от BotFather>
LM_BASE_URL=http://localhost:1234/v1
LM_MODEL=qwen3-vl-8b-instruct-mlx
WHISPER_MODEL=medium
DEFAULT_CURRENCY=BYN
```

В LM Studio: загрузи модель, открой вкладку **Developer → Start Server** (порт 1234).

## Запуск

```bash
uv run main.py
```

## Команды

| Команда | Что делает |
|---|---|
| `/start` | регистрация, приветствие |
| `/report 2026-08-01 2026-08-31` | отчёт за период + диаграмма |
| `/wallets` | балансы всех кошельков + итог в USD |
| `/deposit 100 USD [коммент]` | пополнить spending-кошелёк |
| `/savings 100 USD [коммент]` | пополнить копилку (без аргументов — показать) |
| `/correct USD 90 [savings]` | выставить баланс кошелька в значение |
| `/subs` | подписки; `add <name> <amount> <currency> <day>`, `del <id>` |
| `/categories` | список категорий |
| `/undo` | удалить последний расход |
| `/export` | выгрузить расходы в CSV |

## Архитектура

```
Telegram ─┬─ текст ───────────────┐
          ├─ голос → Whisper ─────┤→ LangGraph-агент → MCP-сервер → SQLite
          └─ фото ────────────────┘        ↑ interrupt (одобрение)
                                            ↑ Qwen3-VL (LM Studio)
```

- `app/db.py` — схема и доступ к БД (raw SQL).
- `app/mcp_server.py` — MCP-сервер: ресурс категорий + тул `save_expenses`.
- `app/mcp_client.py` — stdio-клиент к серверу.
- `app/extract.py`, `app/prompts.py` — вызовы модели (парсинг/правка).
- `app/agent.py` — граф LangGraph с прерыванием и памятью.
- `app/bot.py` — Telegram-бот и команды.
- `app/rates.py` — курсы Нацбанка РБ (in-memory кеш).
- `app/reports.py` — отчёты и диаграммы.
